Not every topic has a complete code solution. The supplied runnable references cover representative patterns and the highest-priority cache and limiter building blocks. Two full original mocks combine several ideas without providing a copyable final answer.

Optional exercises after the core route

Implement binary tree level order, validate BST using inherited bounds, clone a cyclic graph by pointer identity, and merge intervals without mutating input. Add Dijkstra for nonnegative weights if BFS is comfortable. Implement weighted LRU plus TTL and test the combined invariants. Build the larger practical labs only after you can explain why their data structures fit the operations.

For kth largest in a stream, use a size-k min heap over all seen values; duplicates count as separate observations unless specified otherwise. For a static array, sorting is a simple baseline and quickselect offers expected linear time, but its worst case and pivot handling require care. For this first-round route, reliable heap reasoning is the higher-priority transferable skill.

Limits of the material

Fourteen hours provides focused preparation, not exhaustive coverage of every possible interview problem. Deep distributed systems, advanced ML training, and a full Go language course are outside this first coding-round scope. Practice times are estimates. If a prerequisite is unfamiliar, slow down and revisit it rather than treating the time budget as evidence of mastery.
